# Academic Garden MVP 基线

## 产品定位

Academic Garden 是面向青年教师的长期项目成长花园，而非任务管理器。
论文和课程是植物，每一次真实投入都是培育，成果则成为持续可见的职业积累。
界面中称论文项目为“树”，称课程项目为“花”；创建时使用“树（论文）”与
“花（课程）”说明两类植物的对应关系。

## 首轮已确认决策

三项启动决策已经确认。第一版优先服务于本人在本机持续使用，体验稳定后再进行在线化开发。

| 决策 | 默认方案 | 理由 |
| --- | --- | --- |
| 视觉风格 | 像素 RPG 的可爱花园，以草地、土壤地块和像素植物表达成长 | 让养成反馈更直接、更有游戏感，同时保持低压力氛围 |
| 成熟论文收益 | 每周结算；主要作者 `4` 金币，共同作者 `3` 金币 | 一周内可感受到成果回响，差异轻量且不引入评价排名 |
| 运行方式 | 本地浏览器 Web 应用；用 `IndexedDB` 持久化并支持 JSON 导出 | 先在日常使用中验证体验，数据边界保留在线迁移能力 |

## 体验原则

- 正反馈优先：没有记录时不衰败、不掉级、不触发羞辱式提醒。
- 长周期导向：首页呈现正在投入的论文和课程，不提供 Todo 或日历。
- 不制造竞争：无排名、社交比较、期刊等级和引用数计分。
- 可追溯与可迁移：记录属于用户，必须支持导出备份。
- AI 只做理解：AI 将自然语言归类为标准行为，奖励由固定规则计算。

## MVP 区域

| 区域 | 展示对象 | 首页权重 |
| --- | --- | --- |
| 正在生长的花园 | 当前论文、当前学期课程 | 核心 |
| 收获园 | 发表论文、已结束课程、导入历史成果 | 独立浏览 |
| 沉睡花园 | 暂停推进但未删除的项目 | 弱化，可唤醒 |

## 植物生命周期

### 树（论文）

| 阶段 | 意义 |
| --- | --- |
| 种子 | 产生 idea |
| 幼苗 | 正式推进 |
| 成树 | 初稿完成 |
| 开花 | 完成投稿 |
| 收获 | 接收或发表，进入收获园 |

拒稿以后不倒退阶段或扣减成长值，后续迭代中记录为一次正常培育事件。

### 花（课程）

| 阶段 | 意义 |
| --- | --- |
| 种子 | 创建本学期课程 |
| 幼苗 | 完成备课，准备进入课堂 |
| 含苞 | 开始上课，课程正在展开 |
| 盛开 | 完成结课 |
| 绽放 | 提交成绩，形成可继承的课程成果 |

## 固定奖励草案

里程碑每次阶段推进获得 `18` 成长值，不再直接发放金币。日常培育记录转化为当天的
日照、浇水或施肥；当天结算时再统一换算为成长值，并以成长值和所处阶段共同计算每日金币。
当前数值以 `docs/economy-system.md` 为准，采用对数成长收益、阶段系数和轻微随机波动。
成长值是长期累计量，不按 100% 进度条表达；详情界面以数值和预计日金币呈现。
课程的一键授课按授课行为记录为浇水。目前本地原型以关键词规则承担分类适配层，
接入在线 AI 后只替换识别方式，仍沿用“规则固定、AI 不决定数值”的约束。
未命中关键词的文字先按温和的“日常推进”随机给予一类照料值，不阻止记录。收获园成果成长值固定，但仍参与每日金币产出；沉睡园不产金币。

## 实现迭代

| 迭代 | 交付内容 | 验收 |
| --- | --- | --- |
| 已实现：项目骨架 | 创建/历史导入、三区浏览、沉睡/唤醒、基础阶段推进、导出 | 活跃首页不会被历史论文淹没；状态变更可保存 |
| 已实现：培育记录 | 自然语言输入、本地分类适配层、固定培育奖励、近期记录、一键授课 | 输入一句实际进展即可获得稳定反馈 |
| 当前：首页花园与日结 | 行为转化为日照/浇水/施肥、每日成长结算、首页花园全貌、金币装饰商店 | 成长来自当天真实照料，金币可以花在可见装饰上 |
| 生命周期完善 | 在线 AI 分类、拒稿事件、课程继承、详细里程碑 | 生命周期不惩罚中断或失败 |
| 收获与品种 | 每周果实、品种图鉴与解锁 | 奖励直接强化花园体验 |
