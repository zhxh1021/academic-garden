# Academic Garden

面向青年教师的像素风长期项目成长花园原型。当前迭代实现项目建立、历史成果
导入、活跃/收获/沉睡分区，以及论文与课程的培育记录和基础阶段推进。

## 本地运行

日常使用可直接双击项目根目录中的 `打开学术花园.cmd`。它会无窗口地启动本地
服务并打开浏览器；结束使用时双击 `关闭学术花园.cmd`。
如果浏览器仍被系统拦下，服务启动后也可以直接访问 `http://127.0.0.1:4173`。

也可以手动启动：

```powershell
python -m http.server 4173
```

随后访问 `http://127.0.0.1:4173`。请保持使用这个地址，以便浏览器持续读取同一份
本地花园数据。

## 在线访问

推送到 GitHub 的 `main` 分支后，GitHub Actions 会自动部署到 GitHub Pages。
启用后访问：

```text
https://zhxh1021.github.io/academic-garden/
```

如果首次部署失败并提示 `Get Pages site failed`，请到 GitHub 仓库的
`Settings -> Pages` 中确认 `Build and deployment` 的来源为 `GitHub Actions`。
这个设置需要在 GitHub 网页上手动打开一次；打开后重新运行失败的 workflow，
后续每次推送都会自动部署。线上版仍然把数据保存在当前
浏览器的 `IndexedDB` 中；换电脑或换浏览器前，请先用页面右上角导出 JSON 备份。

## 数据

- 浏览器内数据保存在 `IndexedDB` 中。
- 页面右上角可将全部花园数据导出为 JSON 备份。
- 持久化封装在 `src/store.js` 中，后续可替换为服务端 API 或本地数据库。
- 第一版正式采用本地优先方式；体验稳定后再将同一数据边界迁移到在线版本。

## 本轮范围

已实现：

- 创建当前论文的树和课程的花。
- 导入已发表论文或已结课课程。
- 查看正在生长、收获、沉睡三个区域。
- 让活跃项目沉睡、重新唤醒。
- 推进基本里程碑，并用固定规则增加成长值与金币。
- 为活跃植物输入自然语言培育记录，立即得到固定奖励反馈。
- 按当天行为为植物积累日照、浇水或施肥，并在每日结算时统一增加成长值。
- 为课程一键记录“又上了一次课”。
- 在首页查看整座花园全貌，并用金币购买装饰品布置花园。
- 在树的详情页记录作者、发表年份、发表日期和期刊或会议，并查看培育历史。

当前分类由本地关键词适配层完成；下一轮可接入在线 AI 识别，并实现课程继承
与成熟论文的每周果实结算。当前本地网页没有后台常驻任务，因此每日结算会在
下次打开页面时自动处理过去未结算的日期，也可以在首页手动结算今天。
